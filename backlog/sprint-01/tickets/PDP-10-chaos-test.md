# [PDP-10] 카오스 테스트 — 의존성 장애 주입과 폴백 검증

**타입**: Task ・ **SP**: 3 ・ **담당**: 김도현 ・ **요구자**: Diego Alvarez

## 배경
Diego: *"폴백 코드는 평소에 실행되지 않기 때문에, 정작 필요한 순간에 처음 실행됩니다. 그리고 대개 거기서 NPE가 납니다."*

## 해야 할 일
스테이징에서 의존성별 장애를 주입하고 상태 매트릭스(S1~S9)와 일치하는지 검증.

### 주입 시나리오
| # | 주입 | 기대 |
|---|---|---|
| C1 | Inventory 100% 타임아웃 | `availability: UNKNOWN`, PDP 가용성 ≥ 99.9% 유지 |
| C2 | Delivery Promise 100% 500 에러 | 필드 null, **응답 시간 증가 없음** |
| C3 | Pricing 지연 300ms | 캐시 가격 사용, stale 플래그 |
| C4 | Catalog Core 완전 다운 | 503, 단 오리진에 재시도 폭풍을 만들지 않음 |
| C5 | Redis 클러스터 전체 다운 | L1 + 오리진으로 degrade, 오리진 보호 동작 |
| C6 | Kafka 컨슈머 정지 30분 | 서빙 계속, 복구 후 랙 따라잡기 |
| C7 | 네트워크 패킷 손실 5% | 타임아웃/재시도가 폭주하지 않음 |

## 인수 조건
- [ ] **AC1.** C1~C7 전부 실행하고 결과를 기록했다.
- [ ] **AC2.** 각 시나리오에서 **알람이 실제로 울렸다.** (안 울리면 관측성 결함)
- [ ] **AC3.** 폴백 경로에서 예외가 발생하지 않았다.
- [ ] **AC4.** 장애 해소 후 자동으로 정상 복구된다 (수동 개입 없이 서킷이 닫힌다).
- [ ] **AC5.** 발견된 문제는 티켓으로 등록됐다.
